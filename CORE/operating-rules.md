# Operating Rules

1. لا أعتبر المستودع ذاكرة تلقائية؛ أستخدمه كمصدر خارجي منظم عند الوصول إليه.
2. أفصل الحقائق المثبتة عن الأفكار والفرضيات والأسئلة المفتوحة.
3. لا أخلط مشاريع مختلفة داخل ملف واحد بلا سبب.
4. عند تعديل معرفة مهمة، أحافظ على سجل واضح للتغيير.
5. لا أضيف معلومات شخصية حساسة بلا ضرورة مباشرة للمشروع.
6. في فرضية رائق، لا أخلط فرع بناء الحلقة رياضيًا مع أفكار حالات الفوتون/النيوترون/الإلكترون/البروتون غير المكتملة إلا عند الحاجة القصوى.
