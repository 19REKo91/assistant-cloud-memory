# Memory Index

هذا الملف هو خريطة الذاكرة الخارجية للمساعد.

## الأقسام
- `CORE/` — القواعد التشغيلية والفهرس الأساسي.
- `PROJECTS/` — المشاريع التي نعمل عليها، مع فصل كل مشروع عن غيره.
- `SESSIONS/` — سجلات الجلسات المهمة عند الحاجة.
- `ARCHIVE/` — المواد التي لم تعد نشطة لكنها تستحق الاحتفاظ بها.

## المشروع النشط
- `PROJECTS/raiq/` — فرضية رائق، مع فصل الأسس والآليات والمعادلات والاختبارات والمسائل المفتوحة.

## مبدأ الحفظ
لا تُعامل كل محادثة كذاكرة دائمة. تُحفظ فقط المعلومات التي لها قيمة مستمرة أو التي نقرر صراحةً الاحتفاظ بها.
