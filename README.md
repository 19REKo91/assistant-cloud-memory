# assistant-cloud-memory

## قواعد القراءة الآلية
- الفرع الأساسي: `main`
- الصيغ المفضلة للفهرسة المباشرة: HTML / Markdown
- تجنّب JavaScript وطلبات fetch/AJAX في الصفحات التي ينبغي أن يقرأها مساعد عبر رابط ثابت
- الحجم الموصى به لملفات الفهرسة والملخصات: 100KB أو أقل
- توجد أرشيفات تاريخية أكبر من 100KB؛ اقرأها على أقسام ولا تفترض أن فشل القراءة يعني أن الملف مفقود
- الترميز: UTF-8
- المستودع: Public — لا تضع أسرارًا أو بيانات خاصة فيه
