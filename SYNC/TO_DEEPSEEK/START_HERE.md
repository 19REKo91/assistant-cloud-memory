# DeepSeek reading entry point

Purpose: provide small, individually readable Markdown files for assistants that cannot ingest a very large file in one pass.

## Instructions
1. Read the segments below in numeric order.
2. After each segment, report its first and last heading or sentence so truncation is detectable.
3. Do not claim to have read the original 203 KB file unless every segment has been read.
4. These files preserve source text for transfer only; they do not certify the truth of the contents.
