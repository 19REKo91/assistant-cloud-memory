# Nuclear Isotope Audit

مشروع مستقل لتحليل بيانات النظائر النووية ومقارنة فرضية «الصندوق الثنائي والفاقد الطوبي» مع بيانات AME2020 المنشورة. لا يغيّر المشروع ملفات Prism أو أي محرك آخر في المستودع.

## ما يفعله البرنامج

- تنزيل ملفات NUBASE2020 وAME2020 الأصلية من IAEA-NDS / Atomic Mass Data Center.
- حفظ النسخ الخام في `data/raw/` وإعادة استخدامها عند التشغيل اللاحق.
- تحليل سجلات NUBASE مع الاحتفاظ بمؤشر الحالة ورمزها، وفصل مرشحي الحالة الأرضية عن المتزامرات والحالات التي لا يمكن حسم نوعها آلياً.
- تحليل AME2020 باستخدام مواضع الأعمدة الثابتة المعلنة في رأس الملف.
- مطابقة AME2020 مع سجلات NUBASE الأرضية المرشحة فقط؛ لا تُسند كتلة الحالة الأرضية إلى المتزامرات أو المستويات.
- حساب:
  - `U = 2Z + N`
  - `D = Z + 2N`
  - `C_raw = 0.012 A`
  - `C_cancel = 0.008 min(U,D)`
  - `Residual_signed = 0.004 (N-Z)`
  - `Residual_absolute = 0.004 |N-Z|`
- مقارنة المتبقي المطلق بمكافئ نقص الكتلة المشتق من طاقة الربط في AME2020.
- إنتاج CSV، رسوم PNG، تقرير عربي، وتشخيصات للقارئ.

## التشغيل على الهاتف أو الحاسوب

من داخل هذا المجلد:

```bash
python -m pip install -r requirements.txt
python main.py
```

يلزم اتصال إنترنت عند أول تشغيل لتنزيل ملفات المصدر. لا يحتاج التشغيل اللاحق إلى تنزيل جديد ما دامت الملفات الخام موجودة وصالحة.

## التشغيل من GitHub Actions

افتح تبويب Actions ثم اختر **Nuclear Isotope Audit and Cumulative Validation** واضغط **Run workflow**. التشغيل يدوي فقط؛ لا يوجد تشغيل تلقائي عند كل commit. بعد انتهاء المهمة تُرفع نسخة artifact باسم `nuclear-isotope-audit-outputs`، وتُؤرشف ملفات `outputs/` و`data/raw/` في المستودع تلقائياً إذا نجح التشغيل.

## قواعد البيانات والتفسير

- NUBASE2020 وAME2020 مجموعتا بيانات مستقلتان منشورتان؛ راجع أوراقهما العلمية.
- قيمة `0.004(N-Z)` تعريف جبري داخل النموذج وليست نتيجة قياس مستقلة.
- الفرق `C_raw-C_cancel` يساوي `0.004|N-Z|` وليس المتبقي الموقّع في الحالات التي يكون فيها `N<Z`.
- نقص الكتلة المعروض مشتق من طاقة الربط المنشورة: `(BE/A × A) / 931.49410242` بوحدة u.
- هذا المشتق ليس قياساً مستقلاً إضافياً ولا ينبغي الخلط بينه وبين Mass Excess.
- علامة `#` تعني قيمة مقدرة/مستنتجة في ملفات المصدر، و`*` تعني كمية غير قابلة للحساب؛ يحتفظ البرنامج بهذه العلامات ولا يحولها إلى أرقام.
- تصنيف الحالة الأرضية يعتمد على مؤشر NUBASE `i=0` بوصفه مرشحاً؛ لا يُعد حكماً مستقلاً على ترتيب الحالات. المؤشرات 3–6 واللاحقات p/q/r/x قد تمثل مستويات أو متزامرات إضافية، لذلك تحفظ كفئات ملتبسة.
- لا يثبت البرنامج قانوناً فيزيائياً جديداً أو تفسيراً لكتلة النيوكليون أو QCD.
