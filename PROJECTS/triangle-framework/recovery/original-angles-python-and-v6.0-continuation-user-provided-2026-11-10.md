## الجزء الأول: حساب الزوايا الأصلية (الخام)

لحساب الزوايا الأصلية (الخام) لأي عنصر قبل تطبيق أي قواعد إنقاذ (مثل قاعدة 60 أو الهندسة الكروية)، نتبع الخطوات الرياضية التالية بالترتيب. هذه الطريقة هي "القلب" الذي يعمل عليه الكود البرمجي، وتُطبق على كل العناصر، لكن "العناصر الأصلية" هي التي تنتج عنها زاوية ثالثة موجبة (\theta_3 > 0) بدون أي تدخل.

### الخطوات الرياضية لحساب الزوايا الأصلية

**الخطوة 1: حساب الحجم المولي (V_m)**

إذا كان لديك الكثافة (\rho) والكتلة المولية (M):

\[
V_m = \frac{M}{\rho}
\]

**الخطوة 2: التطبيع (Normalization)**

نحول الكثافة والحجم المولي إلى قيم بين 0 و 1 بناءً على الحدود القصوى (الأوزميوم للكثافة، والرصاص للحجم):

\[
\rho_n = \frac{\rho - 1.74}{22.59 - 1.74}
\]

\[
V_n = \frac{V_m - 7.10}{18.27 - 7.10}
\]

**الخطوة 3: حساب الزاويتين الأولى والثانية**

\[
\theta_1 = 80 - 70 \times \rho_n
\]

\[
\theta_2 = 10 + 70 \times V_n
\]

**الخطوة 4: حساب الزاوية الثالثة (الخام)**

\[
\theta_3 = 180 - \theta_1 - \theta_2
\]

ملاحظة المستخدم: إذا كانت \(\theta_3\) الناتجة أكبر من صفر، فهذا يعني أن العنصر "أصلي" ومستقر، ولا يحتاج لقاعدة 60. أما إذا كانت سالبة، فيدخل في مرحلة "الإنقاذ".

### الكود البرمجي (Python) للحساب الأصلي فقط

هذا الكود يقوم بحساب الزوايا الأصلية لأي عنصر، ويخبرك ما إذا كان "مستقراً" أو "يحتاج إنقاذاً":

```python
import math

def calculate_original_angles(element_symbol, rho, M):
    # 1. حساب الحجم المولي
    Vm = M / rho
    
    # 2. التطبيع
    rho_n = (rho - 1.74) / (22.59 - 1.74)
    Vn = (Vm - 7.10) / (18.27 - 7.10)
    
    # 3. الزوايا الأصلية
    theta1 = 80 - 70 * rho_n
    theta2 = 10 + 70 * Vn
    theta3 = 180 - theta1 - theta2
    
    # 4. فحص الحالة
    status = "مستقر (أصلي)" if theta3 > 0 else "منهار (يحتاج إنقاذ)"
    
    return {
        "Element": element_symbol,
        "Density": rho,
        "Vm": round(Vm, 3),
        "theta1": round(theta1, 2),
        "theta2": round(theta2, 2),
        "theta3": round(theta3, 2),
        "Status": status
    }

# --- تجربة على 3 عناصر ---
# التنغستن (أصلي ومستقر)
W = calculate_original_angles("W", 19.25, 183.84)
print(f"{W['Element']}: θ1={W['theta1']}°, θ2={W['theta2']}°, θ3={W['theta3']}° -> {W['Status']}")

# الحديد (أصلي ومستقر)
Fe = calculate_original_angles("Fe", 7.874, 55.845)
print(f"{Fe['Element']}: θ1={Fe['theta1']}°, θ2={Fe['theta2']}°, θ3={Fe['theta3']}° -> {Fe['Status']}")

# الصوديوم (أصلي لكن منهار)
Na = calculate_original_angles("Na", 0.968, 22.99)
print(f"{Na['Element']}: θ1={Na['theta1']}°, θ2={Na['theta2']}°, θ3={Na['theta3']}° -> {Na['Status']}")
```

### مخرجات الكود كما أرسلها المستخدم

- W: θ1=21.21°, θ2=24.85°, θ3=133.94° -> مستقر (أصلي)
- Fe: θ1=59.41°, θ2=9.95°, θ3=110.64° -> مستقر (أصلي)
- Na: θ1=82.59°, θ2=114.34°, θ3=-16.93° -> منهار (يحتاج إنقاذ)

### لماذا تسمى "أصلية"؟

لأنها تعتمد على المعادلات المباشرة فقط، بدون أي "تعديل بشري" مثل قاعدة 60.
العناصر الأصلية هي التي يكون فيها المثلث الإقليدي صالحاً (مجموع زواياه 180°، وكلها موجبة). وهي تمثل أغلب فلزات الجدول الدوري (حوالي 80-90 عنصراً)، بينما العناصر التي تعطي \(\theta_3\) سالبة هي التي تخرج عن نطاق المعايرة الأصلية (مثل المعادن القلوية والغازات) وتحتاج إلى القاعدة الجديدة.
