## 1. الأساس المفاهيمي (6.0)

### 1.1 الرؤوس الثلاثة
- **A (المادة):** الهيمنة الجسيمية — **ليست الصلابة**. الغازات تشير إلى A لأنها جسيمات حرة.
- **B (الزمكان):** الامتداد، الطراوة، التمدد.
- **C (القانون):** الترابط، الخمول، قوة الربط.

### 1.2 النقطة I
- **التعريف:** مركز الدائرة الداخلية (Incenter)، وليس مركز الثقل (Centroid).
- **المعنى:** المسافة إلى الرؤوس = قوة الصفة. المسافة إلى الأضلاع = نسب التوازن.

### 1.3 الطور مقابل الصفة
- **الطور** (غاز/صلب/سائل) يُقرأ من **n** + قرب الانقلاب.
- **الصفة** (مادة/زمكان/قانون) تُقرأ من **موقع I والجرعات**.
- **تحذير دستوري (6.0):** "صلب متماسك" لا تعني "صلب الطور". تعني **قرب التركيب من الصلابة**. الغازات **عمود المادة فيها منهار** ⟹ B غير منطبق عليها.

### 1.4 الموقع vs الصفة
- **الموقع (Closest):** أقرب رأس للنقطة I (A/B/C).
- **الصفة (Dominant):** أكبر قطاع في جرعات 360°.
- **قد يختلفان** (مثل Na: موقع A، صفة B).

## 6. قاعدة 60 — الإنقاذ الكروي (6.0)

### 6.1 النص الحرفي
> **"إذا كانت θ₃ ≤ 0 (المثلث منهار)، أضف 60° إلى θ₃ فقط، مراراً (بمضاعفات n)، حتى تصبح موجبة. ممنوع المساس بـ θ₂. ممنوع المساس بـ θ₁."**

### 6.2 الصيغة الرياضية
$$\theta_3^{\text{adopted}} = \theta_3^{\text{raw}} + 60 \cdot n$$

حيث **n** هو أصغر عدد صحيح يحقق `θ₃_adopted > 0`.

### 6.3 شروط التطبيق
| الشرط | الحالة |
|---|---|
| **θ₃_raw > 0** | ممنوع لمسه. **n=0 إلزامي** (مثل Pb). |
| **θ₃_raw ≤ 0** | يجب الإنقاذ. n ≥ 1. |
| **θ₁** | **لا يُلمس أبداً**. |
| **θ₂** | **لا يُلمس أبداً** (يبقى خاماً حتى لو تجاوز 180°). |
| **الضلع الذي تُضاف إليه 60** | **θ₃ فقط** (زاوية القانون). |

### 6.4 التبعات
- **مجموع الزوايا بعد الإنقاذ:** `θ₁ + θ₂ + θ₃ = 180° + 60°·n` (هندسة كروية، وليس إقليدية).
- **n** = كاشف التمدد: `n=0` مستقر، `n>0` ممتد/غاز.
- **الغازات** تحتاج n كبير (1100–2400).

### 6.5 التصنيف بناءً على n
| n | التصنيف |
|---|---|
| n = 0 | عنصر مستقر (θ₃ خام موجب) |
| 1 ≤ n ≤ 100 | عنصر ممتد (تم تطبيق الإنقاذ) |
| n > 100 | غاز (عمود المادة منهار) |

**المصدر:** 6.0 §3.
**الحالة:** نافذ.
**ملاحظة:** قاعدة 60 **لا تُطبق على θ₁ أو θ₂**. هذا القيد جوهري.

## 7. زوايا النقطة — الجرعات 360° (6.0)

$$S_A = 90 + \frac{\theta_1}{2} \quad \text{(قطاع المادة)}$$

$$S_B = 90 + \frac{\theta_2}{2} \quad \text{(قطاع الزمكان)}$$

$$S_C = 90 + \frac{\theta_3^{\text{adopted}}}{2} \quad \text{(قطاع القانون)}$$

### 7.1 قاعدة المجموع
| الحالة | المجموع |
|---|---|
| **n = 0** | **360°** بالضبط (دائرة سليمة) |
| **n > 0** | **360° + 30·n** (تجاوز الدائرة = مقدار التمدد) |

### 7.2 قاعدة التوازن
- **التوازن المثالي** = 120°/120°/120°.
- **الانحراف** = أكبر قطاع − 120°.
- **الصفة المهيمنة** = أكبر قطاع (A/B/C).

### 7.3 الألوان
- **A** = مادة = 🟩 أخضر.
- **B** = زمكان = 🟦 أزرق.
- **C** = قانون = 🟨 أصفر.

**المصدر:** 6.0 §6.
**الحالة:** نافذ.

## 8. البناء الهندسي (6.0)

### 8.1 الإحداثيات المرجعية
$$A = (0, 0), \quad B = (3, 0) \quad \text{(ثابت AB = c = 3)}$$

### 8.2 أطوال الأضلاع
$$a = \frac{3 \cdot \sin(\theta_1)}{\sin(\theta_3^{\text{adopted}})} \quad \text{(الضلع المقابل لـ A)}$$

$$b = \frac{3 \cdot |\sin(\theta_2)|}{\sin(\theta_3^{\text{adopted}})} \quad \text{(الضلع المقابل لـ B — قيمة مطلقة)}$$

$$c = 3 \quad \text{(AB — ثابت)}$$

**ملاحظة:** القيمة المطلقة في `b` ضرورية لأن `θ₂` قد تكون سالبة (مثل Be, B, C) أو فلكية (الغازات).

### 8.3 إحداثيات الرأس C
$$C_x = b \cdot \cos(\theta_1)$$
$$C_y = b \cdot \sin(\theta_1)$$

### 8.4 النقطة I (Incenter)
$$I_x = \frac{a \cdot A_x + b \cdot B_x + c \cdot C_x}{a + b + c}$$
$$I_y = \frac{a \cdot A_y + b \cdot B_y + c \cdot C_y}{a + b + c}$$

**المصدر:** 6.0 §4.
**الحالة:** نافذ.
**تحذير:** في التسليم الحالي (v1.0)، `a, b, C_x, C_y, I_x, I_y` **غير محسوبة** لأغلب العناصر (0/118). الصيغ جاهزة، لكن التطبيق الفعلي متوقف بقرار صاحب المشروع ("لا تحسب").

## 9. الثابت 0.016 ومعامل الحجم B (6.0 → 6.1)

### 9.1 الصيغة الأساسية (6.0)
$$B = 0.016 \cdot (\theta_3^{\text{adopted}})^2 \quad \text{(GPa)}$$

$$\text{العتبة} = 0.016 \cdot (\theta_2^{\text{raw}})^2$$

### 9.2 قاعدة تصنيف الطور
| الشرط | التصنيف |
|---|---|
| B > العتبة | **متماسك** (قريب من الصلابة) |
| B < العتبة | **رخو** (قريب من السيولة) |

### 9.3 ⚠️ نطاق الصلاحية (6.1 §5.2 — معدّل)
$$\boxed{B = 0.016 \cdot \theta_3^2 \quad \text{صالح فقط في} \quad 110° \leq \theta_3 \leq 155°}$$

| النطاق | الحالة | الإجراء |
|---|---|---|
| θ₃ < 30° | ❌ **فشل كامل** | حتى الترتيب مقلوب (مثال: La خطأ −97%) |
| 30° ≤ θ₃ < 90° | ❌ مُقلَّل أو مبالغ فيه | انحراف > 100% |
| 90° ≤ θ₃ < 110° | ❌ مبالغ فيه | Ag: +58% |
| **110° ≤ θ₃ ≤ 155°** | ✅ **صالح** | خطأ < 25% (Ru: ±3%، Os: ±7%) |
| θ₃ > 155° | ⚠️ نظري | لم يُختبر |

### 9.4 قيد إضافي: معامل الاستطالة ε (6.2 — فرضية مفتوحة)
$$\epsilon = \frac{|\theta_1 - \theta_2|}{\theta_3}$$

**الدليل الأولي:** Re وPt لهما نفس θ₃ (143.70°)، لكن B مختلف (370 vs 230 GPa). ε(Re)=0.0401، ε(Pt)=0.0601. **فرضية:** كلما زاد ε، قلّ B الحقيقي عن نموذج θ₃. **تحتاج اختباراً أوسع.**

### 9.5 حالة المعايرة (6.2.1 — Erratum)
- **3d:** 6/10 داخل المعايرة (Fe, Co, Ni, Cu خارجها — V_m < 7.10).
- **4d:** 9/10 (Y خارجها — V_m = 19.88 > 18.27).
- **5d:** **9/9 داخل المعايرة** (الوحيدة النظيفة).
- **Ln:** 2/15 (فقط Tm, Lu).

**المصدر:** 6.0 §5 → 6.1 §5.2 → 6.2 → 6.2.1 §(د).
**الحالة:** 9.1 نافذ، 9.2 نافذ، 9.3 نافذ، 9.4 **فرضية**، 9.5 **قيد**.

## 13. Erratum 6.2.1 — الإقرار الرياضي الملزم

### 13.1 (أ) العلاقة الجبرية لـ S_C
$$\boxed{S_C = 135 + 35(\rho_n - V_n) + 30n}$$

**متطابقة جبرية، ليست تقريباً.** S_C **ليس قياساً مستقلاً** — هو إعادة تشكيل خطية لـ (ρ_n − V_n).

**البرهان:**
$$\theta_3 = 180 - \theta_1 - \theta_2 = 180 - (80 - 70\rho_n) - (10 + 70V_n) = 90 + 70(\rho_n - V_n)$$
$$S_C = 90 + \frac{\theta_3}{2} = 90 + 45 + 35(\rho_n - V_n) = 135 + 35(\rho_n - V_n)$$

للعناصر المنقذة (n>0): $S_C = 135 + 35(\rho_n - V_n) + 30n$.

### 13.2 (ب) وصف دقيق لمنحنيات d
| السلسلة | البداية | القمة | النهاية | الوصف |
