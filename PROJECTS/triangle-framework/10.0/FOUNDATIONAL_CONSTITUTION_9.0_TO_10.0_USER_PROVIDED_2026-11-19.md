# الوثيقة التأسيسية الشاملة والنهائية: إطار المثلث (من 9.0 إلى 10.0)

**الحالة كما وردت:** الفصل الأول مغلق (محاكي ذري + محاكي روابط تجريبي).  
**المبدأ الحاكم:** العلم والصدق. النموذج يعرف حدوده.

---

## القسم الأول: دستور الذرة (الإصدار 9.0 - محاكي ذري)

### 1. صندوق المعايرة الشامل (9 صناديق)
- الكثافة (ρ): 0.534 (Li) إلى 22.59 (Os).
- الحجم المولي (Vm): 7.0923 (Fe) إلى 18.27 (Pb).
- نصف القطر (R): 28 (He) إلى 203 (K).
- الانصهار (mp): -272.2°C (He) إلى 3422°C (W).
- الكهروسلبية (EN): 0.7 (Fr) إلى 4.787 (Ne - مقياس Allen).
- الزخم المغزلي (Spin): 0 إلى 7 (إلكترونات غير متزاوجة في الذرة الحرة).
- البنية البلورية (CN): 0 إلى 12 (رقم التنسيق في الطور الصلب).
- الطاقة النووية (BE): 0 إلى 8.8 MeV (طاقة الترابط للحديد Fe-56).

### 2. المعادلات التسع (مجموع الزوايا 540°، مجموع الجرعات 1080°)
1. θ₁ (المادة): 80 - 70 * ρ_n حيث ρ_n = (ρ - 0.534) / 22.056
2. θ₂ (الزمكان): 10 + 70 * V_n حيث V_n = (Vm - 7.0923) / 11.1777
3. θ₄ (الحجم): 80 - 70 * R_n حيث R_n = (R - 28) / 175
4. θ₅ (الانصهار): 80 - 70 * mp_n حيث mp_n = (mp + 272.2) / 3694.2
5. θ₆ (الشحنة): 80 - 70 * EN_n حيث EN_n = (EN - 0.7) / 4.087
6. θ₇ (المغناطيسية): 80 - 70 * Spin_n حيث Spin_n = Spin / 7
7. θ₈ (البلورة): 80 - 70 * CN_n حيث CN_n = CN / 12
8. θ₉ (النواة): 80 - 70 * BE_n حيث BE_n = BE / 8.8
9. θ₃ (القانون/الميزان): 540 - (θ₁ + θ₂end + θ₄ + θ₅ + θ₆ + θ₇ + θ₈ + θ₉)

ملاحظة: θ₂end تُحسب بـ mod 360 لضمان الالتفاف الكروي.

### 3. الجرعات التسع
S_x = 90 + θ_x / 2 لكل زاوية (المجموع 1080°).

### 4. الأضلاع
- a = 3 * sin(θ₁) / |sin(θ₃)|
- b = 3 * |sin(θ₂end)| / |sin(θ₃)|
- c = 3

## القسم الثاني: محاكي الروابط والمركبات (الإصدار 10.0 - تجريبي)

### 1. قانون التجميع المعتمد (المسار أ)
- الصيغة: (متوسط الخصائص الموزون → الزوايا → الأضلاع).
- السبب: القانون القديم (متوسط الأضلاع مباشرة) كان يسبب انحيازاً تراكمياً (وصل إلى 24.2% في FeC).

### 2. قانون المضيف والفراغات
- الشرط: الكربون يدخل فراغ الحديد إذا a_C > a_Fe و b_C < b_Fe.
- المضيف: العنصر ذو الضلع b الأكبر. عند التعادل، الأقل كهروسلبية هو المضيف.
- التفسير: التشوه الرباعي (تمدد a، انضغاط b) = التوقيع الهندسي للمارتنسيت.

### 3. البصمة المغناطيسية للمركبات
إضافة الكربون تخفض الزخم المغزلي، فترفع الزاوية θ₇ نحو اللامغناطيسي (الحديد θ₇=40، السمنتيت Fe₃C θ₇=45).

### 4. قانون الهشاشة الأيونية
الهشاشة ليست ارتفاع a/b، بل انخفاضه (الشكل المكعب المتماثل مثل NaCl له a/b=1.04، فلا يوجد اتجاه انزلاق، فيكون هشاً).

## القسم الثالث: نتائج الاختبار المطلق (سجل النزاهة)
- العينة: 20 عنصراً (فلزات، لافلزات، أشباه فلزات).
- النتيجة: 70% توافق.
- التفصيل: اللافلزات (100%)، أشباه الفلزات (100%)، الفلزات (50%).
- سبب الفشل: الضلع a/b يقيس شكل الذرة المفردة، ولا يقيس "المطيلية" (لأن المطيلية خاصية للشبكة البلورية).
- الحكم: النموذج 9.0 هو "محاكي ذري" فقط، ولا يغطي المطيلية البلورية.

---

## القسم الرابع: الثغرات المفتوحة (تسليم للرأس الحادي عشر)
1. المطيلية: تحتاج إلى بُعد شبكي (CN + mp + ρ).
2. متوسط Spin: يحتاج إلى تبرير فيزيائي للمركبات.
3. مقاييس EN: اختلاط (Pauling/Allen) يحتاج إلى توحيد.
4. عتبات التصنيف: عتبات a/b (2 و1) تحتاج إلى اشتقاق رياضي.
