# وثيقة التجميد: الإصدار 7.0 (الرأس السادس والسابع)

**الحالة كما وردت:** نسخة مستقرة ومجمّدة (أساس محاكي الذرة الموسع).  
**المرجع:** يعتمد على صندوق معايرة الإصدار 6.5.0، مع إضافة الشحنة والمغناطيسية.

## 1. الأركان السبعة
1. المادة (θ₁): الكثافة.
2. الزمكان (θ₂): الحجم المولي (مع قاعدة الكرة mod 360).
3. الحجم الذري (θ₄): نصف القطر.
4. الانصهار (θ₅): درجة الحرارة.
5. الشحنة (θ₆): الكهروسلبية.
6. المغناطيسية (θ₇): الزخم المغزلي (Spin).
7. القانون (θ₃): الميزان (540 - مجموع الستة).

## 2. المعادلات الأساسية
- θ₆ = 80 − 70 × EN_n حيث EN_n = (EN − 0.7) / 4.087
- θ₇ = 80 − 70 × Spin_n حيث Spin_n = Spin / 7
- θ₃ = 540 − (θ₁ + θ₂end + θ₄ + θ₅ + θ₆ + θ₇)

## 3. الإنجازات المسجلة في الوثيقة
- المغناطيسية: تم التمييز بين الحديد (θ₇=40) والنحاس (θ₇=80) هندسياً.
- الكهروسلبية: تم التمييز بين الصوديوم (θ₆=75) والكربون (θ₆=40) بدقة.
- التماسك: مجموع الزوايا 540° ومجموع الجرعات 1080°.

## 4. الثغرات التي ورد أنها أدت إلى التجميد
- البيانات: عدم توفر بيانات الكهروسلبية لجميع العناصر (استخدمنا Allen للنيون).
- الزخم: كان يعتمد على "الذرة الحرة" فقط.
