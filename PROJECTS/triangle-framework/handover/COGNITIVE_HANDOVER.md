### 3. الفخاخ العشرة

**فخ 1: S_C ليس مستقلاً**

S_C = 135 + 35(ρ_n − V_n) + 30n — متطابقة جبرية.

S_C(Os)=165.87° لا يعني "استثنائي" — يعني "نقطة المعايرة RHO_MAX".

قبل أي "اكتشاف"، اسأل: هل هو مجرد إعادة صياغة للمدخلات؟

**فخ 2: المعايرة ملوثة**

- 3d: 6/10 (Ni, Fe, Co, Cu خارجها)
- 4d: 9/10 (Y خارجها)
- 5d: 9/9 (الوحيدة النظيفة)
- Ln: 2/15 (Tm, Lu فقط)

قبل أي مقارنة: افحص المعايرة.

**فخ 3: "اكتشاف f-block" مرفوض**

S_C = 135+35(ρ_n−V_n)+30n — لا تصنيف بقيمة واحدة.

**فخ 4: "اكتشاف التكافؤ +2" مرفوض**

رصد شذوذ حسابي (Eu, Yb)، لا استنتاج التكافؤ.

**فخ 5: "الرتابة في 13 عنصراً" مرفوضة**

Pr يكسر: Ce(99.92)→Pr(98.98) = −0.94°.

ليس "ضوضاء" — فرق حقيقي.

**فخ 6: "V-Shape" ملغى**

3d لا يعود للسالب (Zn=+0.075).

الصحيح: "قوس ذو قمة واحدة".

**فخ 7: العدادات خاطئة في المصادر**

- "29 عنصراً n>0" → خطأ. الصحيح 32 (In, Sn مفقودان).
- "89 عنصراً n=0" → خطأ. الصحيح 79 (Nb, Md مفقودان).

عدّ يدوياً قبل تصديق أي عدد.

**فخ 8: التعارضات غير المحلولة**

- Ar: θ₃ مصدر 47.0 / حساب 34.2 → فرق 12.8°
- Kr: 47.0 / 134.2 → فرق 87.2°
- Xe: 47.0 / −165.8 (سالب!) → مستحيل رياضياً
- Rn: 47.0 / 57.2 → متطابق (تصحيح لخطأ سابق)

السبب: θ₂ مقرَّب، أو خطأ نسخي. لا سجل حساب أصلي.

الإجراء: موثقة، غير محلولة. لا تحلها بالتخمين.

**فخ 9: البيانات المفقودة ليست "ناقصة"**

- a, b, C_x, C_y, I_x, I_y: 0/118.
- Vm: 30/118.
- SA/SB لـ Ln: غير متوفرة.

سبب: قرار صاحب المشروع "لا تحسب".

هي فجوات معلنة، لا يُملأها.

**فخ 10: الاستطالة ε فرضية**

Re وPt لهما θ₃=143.70° لكن B مختلف (370 vs 230).

ε = |θ₁−θ₂|/θ₃ قد يفسر — لكنه فرضية، لا قانون.

### 4. البروتوكولات الإلزامية

**قبل أي حساب:**
1. افحص المعايرة (θ₃ ∈ [110°, 155°]؟)
2. افحص الشواذ (Eu, Yb, Pr, Ar, Kr, Xe, Rn)
3. افحص المصدر (6.0؟ 6.2؟ محسوب؟)

**قبل أي "اكتشاف":**
1. اشتق العلاقة الجبرية أولاً
2. إذا متطابقة مع المدخلات → لا تدّعِ اكتشافاً
3. إذا مستقلة → تحقق من المعايرة

**قبل أي "تصحيح" للتعارض:**
1. هل هناك سجل أصلي؟ لا
2. الإجراء: وثّق، لا تحل

**قبل أي "إكمال" لبيانات ناقصة:**
1. هل موجودة في المصدر؟ إذا لا → "غير متوفر"
2. لا تخترع. لا تحسب. لا تفترض.
