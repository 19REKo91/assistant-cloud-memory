# الملف الشامل النهائي: إطار المثلث (الإصدار 6.0 - الدستور الكامل)

## 1. الأساس الفلسفي (المفاهيم الكبرى)

- المثلث: رؤوسه A (المادة)، B (الزمكان)، C (القانون).
- الأضلاع: ليست مجرد خطوط، بل مناطق تأثير.
- النقطة (I): هي مركز الدائرة الداخلية (Incenter)، وليست مركز الثقل (Centroid). هي "قلب العنصر".
- نظرية الجرعات الثلاث (360°): النقطة I تشع 3 مناطق زاوية مجموعها 360° (كل منطقة = 90° + θ/2). أكبر منطقة تحدد الصفة المهيمنة (مادة، زمكان، قانون).
- الطور مقابل الصفة: الطور (غاز/صلب) يُكتشف من عدد التحويلات n. أما الصفات (طراوة، ترابط) فتُقرأ من موقع النقطة I والجرعات.
- تحذير هام: "ضلع المادة" لا يعني الصلابة، بل يعني "الهيمنة الجسيمية". الغازات تشير إلى رأس المادة لأنها جسيمات حرة، وليس لأنها صلبة. الرصاص يشير للزمكان لأنه ممتد وطري.

## 2. حدود المعايرة والمدخلات

- الحدود القصوى (Calibration Extremes): الأوزميوم (Os) للكثافة العليا (22.59)، الرصاص (Pb) للحجم المولي الأعلى (18.27)، الألماس/التنغستن للصلابة (الثابت 0.016).
- المدخلات: الكثافة (ρ) والحجم المولي (Vₘ). (إذا لم يتوفر Vₘ: Vₘ = M / ρ).

### التطبيع (Normalization)
- ρₙ = (ρ - 1.74) / (22.59 - 1.74)
- Vₙ = (Vₘ - 7.10) / (18.27 - 7.10)

### الزوايا الخام
- θ₁ = 80 - 70 × ρₙ
- θ₂ = 10 + 70 × Vₙ
- θ₃ = 180 - θ₁ - θ₂

## 3. القاعدة الذهبية للإنقاذ (الهندسة الكروية والتحويل الذكي)

### أ. قاعدة التحويل الذكي (Smart Modulo)
1. احسب الزوايا الخام.
2. افحص θ₃: إذا كانت θ₃ > 0 (المثلث سليم)، ممنوع لمسه. اترك n=0. (مثال: الرصاص يبقى طرياً ولا نطبق عليه 60 أبداً).
3. إذا كانت θ₃ < 0 (مثلث منهار)، انتقل للخطوة ب.

### ب. التحويل الكروي (Spherical 60)
1. ممنوع المساس بـ θ₂ (الزمكان الحقيقي للعنصر).
2. أضف 60 درجة إلى θ₃ فقط، مراراً (بمضاعفات n)، حتى تصبح موجبة.
3. مجموع الزوايا سيصبح > 180° (هندسة كروية). هذا يعني أن العنصر ممتد ومفلطح، ولا يعيبه رياضياً.
4. n هنا هو "كاشف الغاز/التمدد": (n=0 عنصر مستقر، n>0 عنصر ممتد أو غاز).

## 4. البناء الهندسي والنقطة I

- القاعدة: AB = c = 3.
- الأضلاع:
  - a = (3 × sin(θ₁)) / sin(θ₃)
  - b = (3 × |sin(θ₂)|) / sin(θ₃) (نستخدم القيمة المطلقة للجيب في الهندسة الكروية).
- إحداثيات C:
  - Cₓ = b × cos(θ₁)
  - Cᵧ = b × sin(θ₁)
- النقطة I:
  - Iₓ = (a × Aₓ + b × Bₓ + c × Cₓ) / (a + b + c)
  - Iᵧ = (a × Aᵧ + b × Bᵧ + c × Cᵧ) / (a + b + c)

## 5. الثابت 0.016 والصلابة

- B = 0.016 × (θ₃)² (GPa).
- العتبة: 0.016 × (θ₂)².
- التصنيف: (صلب متماسك) إذا كان B > العتبة، و (طري / قريب من السيولة) إذا كان B < العتبة.
