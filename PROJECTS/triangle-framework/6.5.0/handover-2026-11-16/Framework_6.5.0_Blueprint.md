# إطار المثلث — الإصدار 6.5.0 (الكرة)
# الوثيقة التأسيسية الكاملة (دستور الحساب)

## 0. الحالة والرؤية
- الحالة: نواة مكتملة، مشروع مستمر.
- الرؤية: المفكر (الملك) | المدقق (المحاسب الأول) | المحرك الحسابي (المحاسب الثاني).
- الفلسفة: منشور كروي ثلاثي الأبعاد، لا استبعاد، الانهيار الكروي مقبول.

## 1. صندوق المعايرة (ثوابت مغلقة، مراجع محددة)
| الثابت   | القيمة      | المرجع        |
|----------|-------------|---------------|
| RHO_MIN  | 0.534       | Li            |
| RHO_MAX  | 22.59       | Os            |
| VM_MIN   | 7.0923      | Fe            |
| VM_MAX   | 18.27       | Pb            |
| R_MIN    | 28          | He            |
| R_MAX    | 203         | K             |
| MP_MIN   | -272.2 °C   | He (تحت ضغط)  |
| MP_MAX   | 3422 °C     | W             |

## 2. التطبيع
- ρ_n  = (ρ  − 0.534) / 22.056
- V_n  = (Vm − 7.0923) / 11.1777      حيث Vm = M / ρ
- R_n  = (R  − 28)   / 175
- mp_n = (mp + 272.2) / 3694.2

## 3. الزوايا الخمس (المجموع = 300°)
- θ₁ (المادة)      = 80 − 70·ρ_n
- θ₂_raw (الزمكان) = 10 + 70·V_n
- θ₄ (الحجم الذري) = 80 − 70·R_n
- θ₅ (الانصهار)    = 80 − 70·mp_n
- θ₃_end (القانون)= 300 − (θ₁ + θ₂_end + θ₄ + θ₅)

## 4. قاعدة الكرة (mod 360)
- θ₂_end = θ₂_raw mod 360   (إن كانت النتيجة 0 → تصبح 360)
- n = ⌊θ₂_raw / 360⌋
- الرتابة: الترتيب الفيزيائي حسب (n, θ₂_end) تصاعدياً.

## 5. الجرعات (Doses) — المجموع = 600
- S_A = 90 + θ₁/2
- S_B = 90 + θ₂_end/2
- S_C = 90 + θ₃_end/2
- S_R = 90 + θ₄/2
- S_M = 90 + θ₅/2

## 6. الأضلاع
- c = 3
- a = 3·sin(θ₁) / |sin(θ₃_end)|
- b = 3·|sin(θ₂_end)| / |sin(θ₃_end)|
- a/b (نسبة): <1 مادية سيادية | >2 قانونية سيادية | [1,2] متوازنة
  (ملاحظة المدقق: a/b = sin(θ₁)/|sin(θ₂_end)| — دالة في θ₁,θ₂ فقط)

## 7. الإحداثيات والمساحة
- A=(0,0), B=(3,0), C=(b·cosθ₁, b·sinθ₁)
- I (incenter): I_x = (3b + 3Cx)/(a+b+c) ، I_y = 3·Cy/(a+b+c)
- G (centroid):  G_x = (3+Cx)/3 ، G_y = Cy/3
- r (inradius) = I_y
- O (circumcenter) — غير معرّف في 6.5.0 (فرضية مستقبلية)

## 8. الأعلام (Flags)
- V_OUT: V_n خارج [0,1] (خارج صندوق المعايرة الزمكاني)
- MP_OUT: mp_n خارج [0,1]
- RHO_OUT: ρ_n خارج [0,1]
- θ₃_NEG: θ₃_end < 0  → "انهيار كروي" (مسموح، لا يُعد خطأً)
- NO_DATA: بيانات مفقودة
- NOT_FOUND: الخانة كتبت صراحة NOT_FOUND (لا اختراع)
- EST: قيمة تقديرية
- PREDICTED: صف تقديري بالكامل

## 9. قواعد القيم المفقودة
1. لا اختراع أرقام لإكمال الجدول.
2. الخانة الفارغة تكتب NOT_FOUND.
3. الصف كله علامة NO_DATA إذا فقد mp أو ρ.
4. الكثافة الغازية ممنوعة → تُستخدم الكثافة الصلبة دائماً.
5. قاعدة 60 ملغاة (تسببت بانعكاسات). البديل mod 360.
6. ΣS=600 متطابقة جبرية؛ التحقق الحقيقي هو Σθ=300.
7. الضلع b طول، وليس زاوية 90°.

## 10. تصنيفات التقارير (لأغراض التدقيق)
- MEASURED: صف ذو بيانات مصدرية موثوقة.
- PREDICTED: صف تقديري بالكامل.
- NO_DATA: مفقود جزئياً أو كلياً.
- Ln: اللانثانيدات (La–Lu، 15 عنصراً) — تصنيف مستقل عن MEASURED/VALID.
- An: الأكتينيدات (Ac–Lr، 15 عنصراً) — تصنيف مستقل (وفق نفس مبدأ Ln).
- GAS: عناصر غازية في الظروف القياسية (H, He, N, O, F, Ne, Cl, Ar, Kr, Xe, Rn, Og).
