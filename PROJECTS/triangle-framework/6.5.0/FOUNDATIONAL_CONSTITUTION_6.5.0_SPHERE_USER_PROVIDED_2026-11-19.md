# الوثيقة التأسيسية الشاملة: إطار المثلث (الإصدار 6.5.0 – الكرة)

**الحالة كما وردت:** نواة مكتملة، ومشروع مستمر. (لم يكتمل المثلث بعد).

## القسم 1: الفلسفة والهندسة الأساسية

1. المنشور الكروي: الإطار ليس نظرية كل شيء، بل هو "منشور" يمرر العنصر لتحليل صفاته. المثلث المسطح انتهى، والآن نعمل في فضاء كروي ثلاثي الأبعاد (Spherical Geometry).
2. لا استبعاد: لا يوجد عنصر "غاز" يفلت من المنشور. جميع العناصر الـ118 تدخل، والغازات تُقاس بخصائصها الصلبة.
3. الانهيار الكروي (Spherical Collapse): إذا خرجت زاوية القانون (θ₃) سالبة، فهذا ليس خطأً، بل يعني أن المثلث "انهار" على سطح الكرة (مساحته صفر). هذه حالة هندسية مقبولة ومطلوبة.
4. الدوران المتعاكس: المادة (A) تدور سالباً (انهيار/كتلة)، والقانون (C) يدور موجباً (تردد/طاقة). المثلث هو نتيجة إلغاء الدورانين.

## القسم 3: المعادلات الخماسية

**المجموع الهندسي = 300°، ومجموع الجرعات = 600°.**

### التطبيع
- ρ_n = (ρ - 0.534) / 22.056
- V_n = (V_m - 7.0923) / 11.1777 (حيث V_m = M/ρ)
- R_n = (R - 28) / 175
- mp_n = (mp + 272.2) / 3694.2

### الزوايا الخمس
- θ₁ (المادة) = 80 - 70ρ_n
- θ₂raw (الزمكان) = 10 + 70V_n
- θ₄ (الحجم الذري) = 80 - 70R_n
- θ₅ (الانصهار) = 80 - 70mp_n
- θ₃end (القانون) = 300 - (θ₁ + θ₂end + θ₄ + θ₅)

### قاعدة الكرة (mod 360)
- θ₂end = θ₂raw mod 360 (إذا كانت النتيجة 0، تصبح 360).
- n = floor(θ₂raw / 360) (عدد اللفات).
- الرتابة (Monotonicity): الترتيب الفيزيائي يعتمد على الزوج الحلزوني (n, θ₂end) تصاعدياً. هذا يمنع أي انعكاس.

### الجرعات
- S_A = 90 + θ₁/2
- S_B = 90 + θ₂end/2
- S_C = 90 + θ₃end/2
- S_R = 90 + θ₄/2
- S_M = 90 + θ₅/2

## القسم 4: الأضلاع والإحداثيات

هذه القوانين تختبر طبيعة الروابط.

### أطوال الأضلاع
- c = 3 (ثابت الزمكان)
- a = 3 · sin(θ₁) / |sin(θ₃end)|
- b = 3 · |sin(θ₂end)| / |sin(θ₃end)|
- قانون النسبة (a/b):
  - a/b < 1: مادية سيادية (كثافة، صلابة) مثل الأوزميوم (0.55).
  - a/b > 2: قانونية سيادية (مغناطيسية، مطيلية) مثل الحديد (4.98).
  - 1 ≤ a/b ≤ 2: متوازنة (غازات ومعادن لينة).

### الإحداثيات (النقطة I وG)
- الإحداثيات: A=(0,0), B=(3,0).
- C_x = b · cos(θ₁) ، C_y = b · sin(θ₁)
- المركز I: I_x = (3b + 3C_x) / (a+b+c) ، I_y = (3C_y) / (a+b+c)
- مركز الثقل G: G_x = (3 + C_x) / 3 ، G_y = C_y / 3
- نصف قطر الدائرة الداخلية r = I_y (لأن الضلع AB أفقي).

## القسم 5: سجل الفخاخ والقواعد الصارمة
1. قاعدة 60 ملغاة: كانت تسبب انعكاسات. البديل هو قاعدة الكرة (mod 360).
2. ΣS = 600: متطابقة جبرية. التحقق الحقيقي هو θ₁ + θ₂end + θ₃end + θ₄ + θ₅ = 300.
3. الكثافة الغازية ممنوعة: تُستخدم الكثافة الصلبة دائماً (حتى للغازات).
4. النزاهة أولاً: إذا لم تتوفر بيانات، تُكتب NOT_FOUND ويُعلم العنصر بـ NO_DATA. ممنوع اختراع الأرقام لإكمال الجدول.
5. الضلع b: هو طول، وليس زاوية 90 درجة.
