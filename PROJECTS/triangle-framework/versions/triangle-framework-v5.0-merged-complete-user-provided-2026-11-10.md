## 1. تعريف المثلث (الفلسفة الفيزيائية)

- الرؤوس الثلاثة: A (المادة)، B (الزمكان)، C (القانون).
- الأضلاع الثلاثة:
  - ضلع المادة: الحالة المادية، الصلابة، والقص.
  - ضلع الزمكان: الكثافة، الليونة، والتمدد.
  - ضلع القانون: قوانين قوة الربط، طاقة التماسك، والتفاعلات.
- قاعدة الأقرب فالأقرب:
  - أقرب ضلع/رأس: يحدد النوع الأساسي للعنصر.
  - الثاني: يمنحه صفات مكتسبة.
  - الثالث (الأبعد): تأثيره أقل (نسبة صغيرة جداً، وليس غياباً).

---

## 2. المدخلات الرياضية ومعادلات الزوايا

- المدخلات: الكثافة (ρ) والحجم المولي (V_m). إذا لم يتوفر V_m: V_m = M / ρ.
- التطبيع:
  - ρ_n = (ρ − 1.74) / (22.59 − 1.74)
  - V_n = (V_m − 7.10) / (18.27 − 7.10)
- معادلات الزوايا:
  - θ₁ = 80 − 70 × ρ_n (زاوية المادة)
  - θ₂ = 10 + 70 × V_n (زاوية الزمكان)
  - θ₃ = 180 − θ₁ − θ₂ (زاوية القانون / الإغلاق الهندسي)

---

## 3. البناء الهندسي (من الزوايا إلى المثلث)

- قاعدة مشتركة للمقارنة: AB = c = 3.
- قانون الجيوب:
  - a = 3 × sin(θ₁) / sin(θ₃)
  - b = 3 × sin(θ₂) / sin(θ₃)
- إحداثيات C (بافتراض A=(0,0)، B=(3,0)):
  - C_x = b × cos(θ₁)
  - C_y = b × sin(θ₁)

---

## 4. النقطة (I) — موقع العنصر الداخلي

- تعريفها: مركز الدائرة الداخلية (Incenter)، وليست مركز الثقل. تقاطع منصفات الزوايا الثلاث.
- المعادلات (A, B, C إحداثيات الرؤوس؛ a, b, c الأضلاع المقابلة):
  - I_x = (a·A_x + b·B_x + c·C_x) / (a + b + c)
  - I_y = (a·A_y + b·B_y + c·C_y) / (a + b + c)
- المعنى: المسافة من I إلى الرؤوس تمثل قوة الصفة. المسافة إلى الأضلاع تمثل نسب التوازن.

---

## 5. 🌟 قاعدة 60 درجة (مفتاح الغازات)

- المشكلة: الغازات لها V_m هائل (~22,400 cm³/mol)، مما يجعل θ₂ تنفجر لآلاف الدرجات، وتصبح θ₃ سالبة ضخمة، فينهار المثلث.
- الحل (التفاف طوري): نطرح 60 من θ₂ ونجمعها لـ θ₃ لعدد n من المرات (عدد صحيح).
  - A' = A
  - B' = B − 60n
  - C' = C + 60n
- النتيجة: زوايا موجبة مجموعها 180°. الغازات المثالية تنتج مثلثاً متوازناً تقريباً، يتوافق مع قانون أفوغادرو.

---

## 6. 🚨 معيار الطور (القاعدة الذهبية لكشف الغاز — إلزامية)

### القاعدة الذهبية

- قاعدة 60 هي "كاشف الغاز" المطلق.
- إذا احتاج العنصر إلى تطبيق قاعدة 60 (أي n > 0) بسبب انفجار θ₂ → فهو غاز، بشكل قاطع.
- ممنوع منعاً باتاً استخدام B = 0.016 × θ₃² لتصنيف طور الغاز. الغاز يُكتشف بـ n، ولا يُقاس بمسطرة الصلابة.
- الفلزات الصلبة: لا تحتاج لقاعدة 60 (n = 0).
- الغازات: تحتاج لقاعدة 60 (n كبير جداً).

### خطوات التصنيف

1. الخطوة الأولى (كاشف الغاز): نحسب n.
   - n > 0 → غاز (انتهى التصنيف، لا ننتقل للخطوة الثانية).
   - n = 0 → مادة مكثفة (ننتقل للخطوة الثانية).
2. الخطوة الثانية (صلب/طري — للمواد المكثفة فقط):
   - صلب متماسك إذا: B > 0.016 × θ₂²
   - طري/قريب من السيولة إذا: B < 0.016 × θ₂²

## 7. 🌟 الثابت السحري 0.016 (الربط بين الهندسة والفيزياء)

- التنبؤ بمعامل الحجم: B ≈ 0.016 × (θ₃)² (بوحدة GPa).
- الاستخدام: في الخطوة الثانية من القسم 6 فقط (المواد المكثفة). لا يُستخدم للغازات.
- ملاحظة: الثابت قيد الفحص العميق، موضوع في خزانة الأفكار (القسم 9). راجع أيضاً "الملاحظات المفتوحة" في نهاية الملف.

## 8. الديناميكية (الحرارة)

- إضافة الحرارة تغير الكثافة والحجم المولي → تغير الزوايا → زحزفة النقطة I عبر المثلث (تفسير التحولات الطورية والتبريد).

---

## 9. 🧊 خزانة الأفكار المجمدة (لا تُفتح حتى تكتمل الخريطة)

- النبض والتردد: المثلث يمثل "موجة تردد" أو "بصمة ضوئية" لكل عنصر. التغير في الشكل هو تغير في التردد (Light/Phase).
- سر الثابت 0.016: قد لا يكون معامل معايرة، بل ثابتاً فيزيائياً أعمق يربط الهندسة بالطاقة، أو نسبة كونية لم تُكتشف. (مرشحون: نسبة قوى، جسر بين زوايا لا وحدة لها وضغط بالجيجاباسكال، علاقة بثوابت أساسية).
- الديناميكية الحرارية: كيف ترقص النقطة I داخل المثلث عند التسخين والتبريد.
- قانون الانصهار (تفسير الشريك): عند تسخين الصلب، يتمدد ضلع المادة مؤقتاً. وعند لحظة الانصهار، ينكمش هذا التمدد لتستقر النقطة I على الضلع AB، لأن السائل توازن بين صلابة المادة وسيولة الزمكان.

## 10. قانون العجلة (360°) وتوزيع الخصائص

- النقطة I مركز دائرة كاملة (360°)، وليست مجرد نقطة داخل مثلث 180°.
- القطاع المقابل لكل رأس = 90 + (زاوية الرأس / 2).
- التوازن المثالي: كل قطاع = 120°.
- الانحراف الفيزيائي:
  - قطاع الزمكان > 120° → ميل للسيولة/الغازية.
  - قطاع القانون > 120° → خامل/نبيل/متماسك جداً.
  - قطاع المادة > 120° → خفيف/لين/سريع التأين (مثل الليثيوم).

### دليل تطبيقي (السيزيوم Cs)

- قطاع المادة = 129.68° (> 120°)
- قطاع الزمكان = 108.55°
- قطاع القانون = 121.76°
- النتيجة: تضخم قطاع المادة أدى إلى انهيار الصلابة (نقطة انصهار 28°م) → أطرى معدن. المثلث أظهر الطراوة رياضياً قبل رؤيتها بالعين.

### دليل تطبيقي (التنغستن W)

- قطاع القانون = 156.72° (> 120° بكثير)
- قطاع الزمكان = 102.67°
- قطاع المادة = 100.61°
- النتيجة: تضخم قطاع القانون على حساب الزمكان والمادة = دليل رياضي على أعلى قوة ترابط وأعلى نقطة انصهار في الجدول الدوري (3422°م).

def compute(sym, name, rho, M):
    Vm = M / rho
    rn = (rho - RHO_MIN) / (RHO_MAX - RHO_MIN)
    Vn = (Vm - VM_MIN) / (VM_MAX - VM_MIN)
    th1 = 80 - 70*rn
    th2 = 10 + 70*Vn
    th3 = 180 - th1 - th2
    n = 0
    # قاعدة 60 — كاشف الغاز (القاعدة الذهبية: n>0 => غاز)
    while th3 <= 0 or th2 >= 180:
        th2 -= 60; th3 += 60; n += 1
        if n > 200: break
    if th3 <= 0 or th2 <= 0 or th1 <= 0:
        return None
    t1, t2, t3 = map(math.radians, (th1, th2, th3))
    s3 = math.sin(t3)
    if abs(s3) < 1e-9: return None
    a = AB*math.sin(t1)/s3
    b = AB*math.sin(t2)/s3
    c = AB
    Ax, Ay, Bx, By = 0, 0, 3, 0
    Cx, Cy = b*math.cos(t1), b*math.sin(t1)
    S = a + b + c
    Ix = (a*Ax + b*Bx + c*Cx)/S
    Iy = (a*Ay + b*By + c*Cy)/S
    Bk = K*th3**2
    Thr = K*th2**2
    # القاعدة الذهبية: n>0 => غاز. n=0 => مكثف (صلب/طري)
    if n > 0:
        phase = "غاز"
    else:
        phase = "صلب" if Bk > Thr else "طري/قريب من السيولة"
    return dict(Symbol=sym, Name=name, Density=rho, MolarMass=M,
                theta1=round(th1,3), theta2=round(th2,3), theta3=round(th3,3),
                Ix=round(Ix,4), Iy=round(Iy,4),
                BulkModulus_GPa=round(Bk,2), Threshold_GPa=round(Thr,2),
                Phase=phase, n60=n)

rows = [compute(*e) for e in ELEMENTS]
df = pd.DataFrame([r for r in rows if r])
print(df.to_markdown(index=False))
print("\\n--- CSV ---")
print(df.to_csv(index=False))

"أقرب ضلع" مقابل "أقرب رأس": الفلسفة تقول إن أقرب ضلع يحدد النوع، لكن I هي Incenter (متساوية البعد عن الأضلاع الثلاثة بالتعريف)، فمفهوم "أقرب ضلع" غير محدد رياضياً. التحليلات العملية (المجموعة 11، السيزيوم، التنغستن) تستخدم المسافة إلى الرؤوس أو القطاعات — وهذا متسق، لكنه يحتاج توحيداً في الفلسفة.
4. Li و Be: مستبعدان تلقائياً (ρ < 1.74). يحتاجان معالجة خاصة (توسيع النطاق؟ معامل آخر؟).
5. عمود الطور في جدول القسم 12: قديم (قبل القاعدة الذهبية). القيم الرقمية صحيحة، لكن التسميات ستتغير عند إعادة التشغيل ("سائل" → "طري/قريب من السيولة").
