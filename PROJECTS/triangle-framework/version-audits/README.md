# سجل تدقيق إصدارات إطار المثلث الكوني

هذا المجلد يسجل كل إصدار مستقلاً. لا يجوز دمج المعادلات أو الثوابت أو نتائج الإصدارات المختلفة دون نص صريح من دستور الإصدار المعني.

- [6.5.0 — المعادلات ونتائج تدقيق الإدخال والهندسة](6.5.0_AUDIT_NOTES_2026-11-14.md)
- [7.0 — المعادلات المتاحة والتعارضات المفتوحة](7.0_AUDIT_NOTES_2026-11-14.md)
- [8.0 — معادلة الرأس الثامن والتعارضات المفتوحة](8.0_AUDIT_NOTES_2026-11-14.md)

## قواعد السجل
1. المصدر الأصلي للإصدار هو المرجع الأول؛ هذا السجل لا يحل محله.
2. كل صيغة غير مطابقة بعدُ مع المصدر الأصلي موسومة بأنها مؤقتة/غير مؤكدة.
3. لا تُخترع القيم المفقودة، ولا تُدمج نسخ البيانات.
4. الاختبار الجبري لا يثبت صحة فيزيائية أو تجريبية.
5. لا تُعدّل ملفات الدساتير أو المحركات ضمن تسجيل الملاحظات.
