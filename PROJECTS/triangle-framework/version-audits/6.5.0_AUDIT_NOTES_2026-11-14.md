## المعادلات كما ينفذها المحرك
الحجم المولي:
[
V_m=M/\rho
]

التطبيع:
[
\rho_n=(\rho-0.534)/(22.59-0.534)
]
[
V_n=(V_m-7.0923)/(18.27-7.0923)
]
[
R_n=(R-28)/(203-28)
]
[
mp_n=(mp_C+272.2)/(3422+272.2)
]

الزوايا:
[
\theta_1=80-70\rho_n
]
[
\theta_{2raw}=10+70V_n
]
[
\theta_{2end}=\theta_{2raw}\bmod360
]
إذا كانت نتيجة modulo صفراً، يستبدلها المحرك بـ360°. كما يحسب:
[
n_{turns}=\lfloor\theta_{2raw}/360\rfloor
]
[
\theta_4=80-70R_n
]
[
\theta_5=80-70mp_n
]
[
\theta_3=300-(\theta_1+\theta_{2end}+\theta_4+\theta_5)
]
وبالتالي:
[
\sum\theta=300^\circ
]

الجرعات:
[
S_A=90+\theta_1/2,\quad S_B=90+\theta_{2end}/2
]
[
S_C=90+\theta_3/2,\quad S_R=90+\theta_4/2
]
[
S_M=90+\theta_5/2
]
وبالتالي:
[
\sum S=600^\circ
]

الأضلاع والإحداثيات:
[
a=3\sin(\theta_1)/|\sin(\theta_3)|
]
[
b=3|\sin(\theta_{2end})|/|\sin(\theta_3)|,\quad c=3
]
[
A=(0,0),\quad B=(3,0)
]
[
C_x=b\cos(\theta_1),\quad C_y=b\sin(\theta_1)
]
ويحسب المحرك Ix,Iy بوزن المحيط، وGx,Gy كمركز ثقل، وinradius_r=Iy، وarea_projected=|0.5\times3\times C_y|.

التصنيف:
- MATERIAL_SOVEREIGN إذا a/b<1
- LAW_SOVEREIGN إذا a/b>2
- BALANCED خلاف ذلك.

## ملاحظات الاتساق الرياضي والهندسي
1. مجموع 300° ومجموع الجرعات 600° نتيجتان جبريتان تفرضهما معادلة الإغلاق وتعريف الجرعات؛ لا يمثل 300° مجموع زوايا مثلث إقليدي.
2. في تطبيق الصيغ على 111 صفاً مكتمل المدخلات، ظهرت 19 حالة theta3 سالبة، وحالة Hs ذات theta1 سالبة تنتج a سالباً.
3. عند اختبار المسافة الإقليدية BC من الإحداثيات المنشأة في الكود مقابل الضلع a المحسوب، لم تتطابق القيم في الحالات الـ111. هذا اختبار اتساق التمثيل الإقليدي فقط؛ والمحرك يصرح في ترويسة الملف بأنه لا يدّعي أن نظام 300° مثلث إقليدي، وأن الأضلاع/الإحداثيات مخرجات نموذجية محفوظة وفق الدستور. لذلك لا يُسجل هذا وحده كإثبات أن تنفيذ الدستور خالف قصده، بل كحدّ واضح إذا أريد تفسير المخرجات هندسياً كمثلث إقليدي.
4. يحفظ المحرك n_turns لكنه يستخدم theta2_end في معادلة theta3 وبقية حسابات الأضلاع؛ أثر فقد معلومات الدورات بعد modulo يحتاج قراراً تفسيرياً من دستور الإصدار.
5. self_test يختبر هويات مجموع الزوايا والجرعات وحد modulo فقط؛ لا يختبر صحة بيانات العناصر أو الاتساق الإقليدي للأضلاع والإحداثيات.
