# نقطة العمل الحالية — بناء مثلث كل عنصر وتحديد موضعه بالمركز الداخلي
**التاريخ:** 2026-11-22  
**الحالة:** نقطة عمل متابعة، وليست تعديلاً للنسخة المرجعية المعتمدة.

## 1. الهدف الحالي
بناء مثلث هندسي مستقل لكل عنصر من العناصر، وفق إدخال زاويتين فقط بالترتيب:
1. إدخال الزاوية A.
2. إدخال الزاوية B.
3. حساب الزاوية الثالثة تلقائياً: C = 180° - A - B.
4. إنشاء المثلث مع تثبيت الضلع الأساسي AB = 3.
5. حساب منصفات الزوايا الثلاث.
6. تقاطع منصفات الزوايا هو المركز الداخلي I (Incenter)، وهو موضع العنصر داخل مثلثه.

موضع العنصر داخل المثلث ليس مدخلاً مستقلاً، ولا يُستبدل بمركز الثقل G. لا تخلط I مع G.

## 2. الصيغ الهندسية
اعتبر رؤوس المثلث:
- A_v = (0,0)
- B_v = (3,0)
- C_v = (b cos(A), b sin(A))

حيث:
- a = BC = 3 sin(A) / sin(C)
- b = CA = 3 sin(B) / sin(C)
- c = AB = 3

المركز الداخلي هو المتوسط الموزون لرؤوس المثلث بأطوال الأضلاع المقابلة:
I = (a A_v + b B_v + c C_v) / (a+b+c).

- c=3

## 5. حدود الصلاحية الهندسية
- المثلث الإقليدي العادي يتطلب زوايا موجبة ومجموعها 180°؛ وبصياغة الإدخال الحالية يلزم A>0 وB>0 وA+B<180°.
- حالات الإنقاذ/قاعدة 60 أو الجرعات التي يكون مجموعها غير 180° لا تتحول تلقائياً إلى مثلث إقليدي. تُفصل وتُعلّم كحالات غير محسومة إلى أن تُعتمد قاعدة تحويل صريحة.
- لا تخترع زوايا A أو B لأي عنصر. استخدم فقط بيانات موثقة من مجموعة محددة المصدر والإصدار.
- لا تدّعِ أن مثلثات العناصر الـ118 قد بُنيت أو حُسبت؛ الموجود حالياً تحقق Li وFe فقط ضمن تصديري Triangle Lab.

## 6. حالة النسخة المرجعية
النسخة المرجعية المجمدة لا تُعدّل. أي توسيع أو إعادة موازنة أو اختبار لاستيعاب العناصر الـ118 يكون في مسار/نسخة تجريبية منفصلة، ولا يُدمج أو يستبدل المرجع إلا بموافقة صريحة من المستخدم.

## 7. نقطة الاستئناف للمساعد
عند استئناف العمل:
1. اقرأ هذه المذكرة أولاً، ثم راجع الملفات ذات الصلة في المستودع قبل أي سؤال أو استنتاج.
2. التزم بتسلسل A ثم B ثم C ثم إنشاء المثلث ثم حساب I.
3. لا تعد إلى فكرة استخدام إحداثيات خريطة الكتلة العامة لتحديد I؛ تلك طبقة تموضع/عرض خارجية مستقلة إن طُلبت صراحة.
4. الخطوة المنطقية التالية هي تحديد مجموعة الزوايا A وB التي سنستخدمها لكل عنصر، مع توثيق المصدر والإصدار، ثم تدقيق صلاحية الأزواج قبل بناء المثلثات.
5. لا تجرِ أي تعديل آخر على المرجع أو البيانات الأصلية.
